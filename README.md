# 🛰️ Network Monitoring and Diagnosis System (NMDS)


**NMDS** is a Python-based project designed to monitor, diagnose, and analyze network performance using essential metrics such as speed, latency, and packet loss. It aims to assist in real-time network troubleshooting and performance evaluation by leveraging diagnostic tools and structured analysis.


> 🚧 **This project is a work in progress.** Data preprocessing and machine learning components are under development.


---


## 📌 Features


- Track and log basic network metrics: speed, latency, and packet loss

- Collect data using tools like:

  - `ping`

  - `traceroute`

  - `netspeed-cli` or equivalent

- Classify network coverage status: **Good**, **Moderate**, or **Poor**

- Console-based user interface for ease of testing and expansion



## 🚀 Getting Started


### Prerequisites


- Python 3.7+

- Works on Windows (Linux/MacOS support planned)
